# Free Robux Rewards Privacy Policy

This folder is ready to publish with GitHub Pages.

## Recommended GitHub Pages setup

1. Create a new public repository, for example:
   `free-robux-rewards-privacy`
2. Upload `index.html` to the repository root.
3. In GitHub, open:
   **Settings → Pages**
4. Under **Build and deployment**, choose:
   **Deploy from a branch**
5. Select:
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.
7. GitHub will provide a public URL similar to:
   `https://YOUR_GITHUB_USERNAME.github.io/free-robux-rewards-privacy/`
8. Put that URL in:
   - Google Play Console → App content / Privacy policy
   - Your app's Privacy Policy menu item
   - AdMob / consent-related surfaces if requested

## Before publishing

Confirm these product decisions match the app:
- App public name
- Support email
- Minimum age (currently written as 13+)
- Google/Firebase/AdMob services actually used
- Account deletion method
- Whether Analytics/Crashlytics/Performance Monitoring are enabled
- Whether you collect a Roblox username or payout identifier

If any of these differ, edit the policy before publishing.
